# ota-fleet-rollout (python bootstrap)

本地可复现的 **OTA 固件分批发布与设备编队管理**模拟服务：
设备注册/心跳、固件校验、分批灰度、暂停继续、失败率阈值熔断、
看门狗超时重试/搁置、断线重连增量补齐、单设备与整批回滚。
仅使用本地 JSON 快照持久化与进程内锁，无外部服务、无真实凭据。

## 快速开始

```bash
uv sync                                   # 安装依赖
.venv/bin/pytest -q                       # 40 个异常链路/并发单测
.venv/bin/python scripts/demo.py          # 端到端演示（熔断/看门狗/回滚）
.venv/bin/uvicorn main:app --reload       # HTTP 服务，/docs 为 Swagger
```

## 能力一览

- **身份可信**：注册唯一身份 + 一次性令牌（PBKDF2 哈希存储）；重复注册、
  伪造令牌、过期/重复心跳一律拒绝，原因码可区分且不覆盖既有状态。
- **版本兼容**：固件按型号/硬件匹配，升级方向与允许的源版本白名单强校验，
  降级必须显式授权。
- **灰度发布**：批次容量、失败率阈值、阶段超时与重试次数均可配置；
  达阈值自动停止后续批次，未认领任务确定性搁置，已下发设备继续收敛到终态。
- **回滚可控**：只允许回到升级前版本（固件必须仍在库且兼容）；
  升级中禁止回滚；整批回滚逐设备归类拒绝，保留可追溯链，不留半更新设备。
- **看门狗 & 重连**：无进展重试→搁置；设备重连心跳后搁置任务恢复，
  终态计数先冲销再收敛，离线进度增量上报不重复计数、不丢失。
- **并发一致**：所有状态迁移在一把锁内原子完成；并发认领/上报/回滚
  不出现计数偏差、重复回滚或状态倒退；写盘 tmp+fsync+rename，重启可恢复。

## 目录

```

```

错误响应统一为 `{"error": {"code", "reason", "message"}}`，
完整原因码表见 `docs/ota_design.md`。
